# Tic-Tac-Toe

This is a tic-tac-toe game project that I made for the Odin Project course,
using HTML, CSS and Javascript.


I tried to come up with logical ways to track each player's positions on the
game board, and compare each players marks on the board with a series of
possible winning combinations.

I also had to create a function that switches turns with each player's move,
each turn counts the positions taken on the board in player one's score or
player two's, as well as displays an "X" or an "O" on the chosen area of
the game board.

I also created dialog boxes so the users can input their names and start a new
game, and a dialog box to announce the results of the game.



Here is a link to the Odin Project tic-tac-toe project lesson that I
was following: https://www.theodinproject.com/lessons/node-path-javascript-tic-tac-toe
